1. VALUE PROPOSITION & POSITIONING
- Primary Pitch: Zero-dependency, offline-first Python AST analyzer providing instantaneous dead code detection, unused import cleanup, and code duplicate detection with an accessible Tkinter GUI, CLI automation, and a local offline PWA companion.
- Differentiation:
  * Zero external runtime dependencies (100% Python Standard Library).
  * Built-in code similarity detection (difflib SequenceMatcher).
  * Interactive Desktop GUI + Headless CLI + Local PWA companion.
  * Reversible Auto-Fix with automatic atomic `.bak` backup.
  * 100% Local-First & Zero Network Egress (privacy guaranteed).
  * Full 6-language internationalization (de, en, es, zh, ja, ru).

2. AUDIENCE SEGMENTATION
- Python Refactoring Engineers: Scanning large codebases for dead definitions and unused imports before major refactorings.
- Solo Developers & Indie Hackers: Lightweight, zero-setup AST tool that works out-of-the-box without configuring complex linters.
- Enterprise & Air-Gapped Environments: 100% offline, zero-egress, unprivileged user execution (RunAsInvoker) complies with strict security guidelines.
- CI/CD Automation Teams: Headless CLI returning deterministic exit codes and standard `methodenanalyser-report-v1.json` reports.
- Students & Python Beginners: Visual GUI inspection of AST structure, method hierarchies, and code duplication.
