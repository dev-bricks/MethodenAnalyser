# Support — MethodenAnalyser

## Deutsch

### Kontakt & Hilfe

Bei Fragen, Fehlermeldungen oder Funktionswünschen stehen folgende Support-Kanäle zur Verfügung:

- **GitHub Issues** (bevorzugt): <https://github.com/dev-bricks/MethodenAnalyser/issues>
- **Dokumentation & Quellcode**: <https://github.com/dev-bricks/MethodenAnalyser#readme>
- **E-Mail-Support**: `support@lukasgeiger.com`
- **Sicherheitsmeldungen**: Sicherheitsrelevante Schwachstellen bitte vertraulich über [SECURITY.md](SECURITY.md) oder via GitHub Security Advisories melden.

### Hilfreiche Angaben bei Fehlerberichten

1. Verwendetes Betriebssystem und Architektur (z. B. Windows 11 x64, macOS Sonoma, Ubuntu 24.04).
2. Python-Version (`python --version`) bzw. MSIX/EXE-Version.
3. Fehlermeldung oder Traceback aus der Konsole oder der GUI.
4. Minimales Code-Beispiel zur Reproduktion (bitte keine vertraulichen Kundendaten oder Secrets anhängen).

## English

### Contact & Support

For questions, bug reports, or feature requests, please use our official support channels:

- **GitHub Issues** (preferred): <https://github.com/dev-bricks/MethodenAnalyser/issues>
- **Documentation & Source Code**: <https://github.com/dev-bricks/MethodenAnalyser#readme>
- **Email Support**: `support@lukasgeiger.com`
- **Security Vulnerabilities**: Please report security issues confidentially according to [SECURITY.md](SECURITY.md).

### Useful Information for Bug Reports

1. Operating system and architecture (e.g., Windows 11 x64, macOS Sonoma, Ubuntu 24.04).
2. Python version (`python --version`) or MSIX/EXE release version.
3. Error messages or console tracebacks.
4. Minimal reproducible Python code snippet (redact private data and secrets).
